## 手指與觸控筆

layerling 可在平板的瀏覽器中執行，也可從主畫面以應用程式的方式執行。手指的作用相當於滑鼠左鍵。平板沒有的三樣東西——滑鼠右鍵、Shift 鍵和滾輪——各有自己的替代方式：

| 你想要 | 在平板上 |
| --- | --- |
| 選取一個實體 | 輕觸它。 |
| 選取多個實體 | 手指按住不動半秒，選擇 {{ui:contextMenu.selectMultiple}}，然後逐一輕觸實體。再次輕觸已選取的實體會將它移出選取範圍。 |
| 全選實體 | 在空白處按住手指不動半秒，選擇 {{ui:contextMenu.selectAll}}。 |
| 開啟右鍵選單 | 在實體上或空白處按住手指不動半秒。 |
| 移動實體 | 拖曳它。 |
| 調整實體大小、旋轉或抬高 | 拖曳它的控制柄，也就是周圍的小方塊和箭頭。手指稍微偏一點也抓得到。 |
| 轉動視圖 | 在空白處用一根手指，或拖曳視圖立方體。 |
| 縮放視圖 | 兩根手指：張開以拉近，捏合以拉遠。 |
| 移動視圖 | 兩根手指併攏滑動。 |
| 清除選取 | 輕觸空白處。但在 {{ui:camera.touchRotate}} 開啟時不行，那時單指用於轉動視圖；而在 {{ui:contextMenu.selectMultiple}} 中，第一次輕觸空白處只會結束該模式並保持選取不變，再輕觸一次才會清除。 |

## 選取多個實體

沒有 Shift 鍵時，長按選單中的 {{ui:contextMenu.selectMultiple}} 就等同於電腦上的 Shift+點擊。開啟期間會有訊息提示，每次輕觸實體會將它加入選取範圍或移出。輕觸空白處，或在鍵盤上按 [[Esc]]，會結束該模式並保持選取不變。這段期間手指在空白處仍可轉動視圖。之後 {{ui:editor.tool.group}}、{{ui:editor.tool.align}} 或移動操作都會作用於你選取的所有實體。

同一選單中還有 {{ui:contextMenu.carry}}，也就是觸控螢幕上的 [[C]] 鍵。選取範圍接著會跟著手指越過其他實體的各個面；輕觸一下即可將它放到你輕觸的那個面上，斜面也可以，而且第一次輕觸就足夠。也可以搜尋「set down」或「cruise」找到這個選單項目（指令搜尋，鍵盤上為 [[Ctrl]]+[[K]]）。

## 轉動與縮放視圖

在空白處用一根手指轉動視圖，兩根手指縮放並移動視圖。從實體上開始的手指操作的是實體，不是視圖。如果你希望它改為轉動視圖，請在檢視列開啟 {{ui:camera.touchRotate}}：此後無論從哪裡開始，單指都會轉動視圖而不是選取。這個開關只在有觸控螢幕的裝置上顯示。

左上角的視圖立方體在拖曳時會轉動視圖，輕觸它的某個側面、角或邊則會跳到該視圖。參見[視圖與工作平面](chapter:view-and-workplane)。

## 控制柄、小點與觸控筆

指尖會遮住它所瞄準的東西。layerling 讓手指比滑鼠指標伸得更遠一點，也夠得到控制柄、點、線和邊，但觸控筆更精細。這適用於平板辨識為筆的筆，例如 Apple Pencil 或 S Pen。帶橡膠筆尖的普通觸控筆會被螢幕當成手指，並不比手指精細，所以只能像手指一樣使用。在 iPad 上，懸停在螢幕上方的 Apple Pencil 稍後也會用一個小氣泡顯示控制項的名稱，就像滑鼠指標的工具提示那樣。

如果實體在兒童或匆忙的手觸碰時會滑動，請在設定中開啟 {{ui:workspace.selectBeforeMoving}}：這樣必須先選取實體，只有下一次拖曳才會移動它。

## 在 iPad 或 iPhone 上

- **將它安裝為應用程式。** 在 Safari 中輕觸分享圖示，選擇「加入主畫面」。應用程式會在自己的視窗中開啟，沒有網址列，而且沒有連線也能使用，參見[離線與安裝](chapter:offline-and-install)。
- **你的設計存在瀏覽器中。** 沒有帳號，也不會上傳任何內容。Safari 有自己的防追蹤規則：如果七天內沒有在 Safari 造訪某個網站，它就會刪除該網站儲存的內容。加入主畫面的網頁應用程式不受這條規則限制，WebKit 的文件如此說明。這也是更應該從主畫面使用應用程式，並備份重要作品的理由：起始頁上的 {{ui:dashboard.backupAll}} 會把所有設計打包成一個檔案。
- **檔案。** Safari 只允許頁面透過下載寫入檔案，所以 {{ui:editor.export}} 會把檔案放進「檔案」應用程式的「下載項目」，鍵盤上的 [[Ctrl]]+[[S]] 會再次下載它；參見[檔案與儲存](chapter:files-and-saving)。
- **不需要鍵盤。** 每個工具在功能區都有按鈕，數字欄位會叫出螢幕鍵盤。iPad 上的鍵盤則會帶來[鍵盤快速鍵](chapter:shortcuts)。 實體旁的數值框要點第二下才會開啟數字輸入框：第一下只是標記它，所以手指誤觸到它也不會彈出鍵盤。

## 帶兒童的工作坊

手指和橡膠筆尖的觸控筆在這裡用法相同。有兩項設定能讓課堂更輕鬆：{{ui:workspace.selectBeforeMoving}} 讓觸碰不會意外移動實體，{{ui:camera.touchRotate}} 讓單指一律轉動視圖。功能區的「說明」群組中的問號按鈕會開啟 {{ui:interactiveHelp.title}}：此時輕觸任何按鈕、欄位或控制柄都會得到說明，再按同一按鈕或按 [[Esc]] 即可離開。

要讓整個班級使用，請在設定中開啟 {{ui:workspace.simpleMode}}。功能區之後只保留工作坊會用到的工具（複製、貼上、建立副本、刪除、復原、群組、鏡像、倒角、圓角、抽殼、對齊、匯出），形狀庫只留一份簡短清單，按鈕更大，起始頁只顯示設計，別無其他：沒有最新消息、沒有歡迎文字、沒有說明按鈕，也沒有連到 layerling 之外的連結。開啟只需輕觸一下；關閉則要按住接著取代它的那個按鈕兩秒。以 `?mode=simple` 結尾的連結會為開啟它的裝置開啟此模式，`?mode=full` 會再次關閉。在伺服器上執行 layerling 的人可以用 `LAYERLING_SIMPLE_MODE=true` 讓所有人一開始就進入此模式，或用 `always` 為所有人固定下來，讓程式沒有離開此模式的開關；參見 README。
