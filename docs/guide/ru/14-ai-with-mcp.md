layerling поставляется с сервером MCP. MCP - это стандарт, через который помощник с ИИ может пользоваться инструментами в других программах. С его помощью клиент ИИ, например Claude или Codex, видит открытую вкладку редактора и работает в ней: создаёт фигуры, меняет размеры, группирует, вырезает, скругляет кромки, читает сцену и делает снимки вида. Вы описываете деталь, ИИ её строит, вы смотрите и в любой момент можете вмешаться.

Связующее звено между клиентом ИИ и редактором работает **локально на вашем компьютере**. Но учтите: то, что читает ИИ, то есть сцена и снимки вида, уходит поставщику вашего клиента ИИ, как и любой другой ввод там.

> **Важно:** связующее звено MCP есть только в сервере разработки, который вы запускаете сами на своём компьютере. На layerling.com и в установках со статическим хостингом оно отключено.

## Настройка

1. Возьмите layerling с [GitHub](https://github.com/henmedia/layerling) и запустите его в папке проекта командой `npm run dev`. Node.js должен быть установлен. В Windows об этом позаботится строка быстрого запуска в README.
2. Откройте вкладку редактора, например `http://127.0.0.1:3000/?editor=1`.
3. Подключите свой клиент ИИ к серверу MCP. Клиент запускает его сам командой `node scripts/layerling-mcp-server.mjs`.

### Claude Code

Устанавливать ничего не нужно: в проекте есть `.mcp.json`, который регистрирует сервер, и навык в `.claude/skills/layerling-mcp-skill`. Откройте папку layerling в Claude Code и попросите, например: «Используй инструменты layerling MCP, чтобы перечислить мои открытые редакторы и посмотреть сцену.»

### Claude Desktop

Claude Desktop не читает файлы проекта. Впишите сервер в его собственную конфигурацию. Как образец используйте `docs/mcp/claude-desktop-config.example.json` в проекте, заменив путь к скрипту на абсолютный путь на вашем компьютере. Затем перезапустите Claude Desktop.

### Codex

Скопируйте навык из `docs/skills/layerling-mcp-skill` в папку навыков Codex, впишите сервер в конфигурацию Codex по образцу `docs/mcp/codex-config.example.toml` и перезапустите Codex.

Подробные инструкции для всех трёх есть в [README на GitHub](https://github.com/henmedia/layerling/blob/main/README.md#layerling-mcp-skill).

## Что умеет ИИ

ИИ работает с теми же функциями, что и вы, тем же путём, что и ваши действия в редакторе. Новые функции layerling сразу получают своё действие MCP. Инструменты:

| Инструмент | Что он делает |
| --- | --- |
| `layerling_list_editors` | перечисляет открытые вкладки редактора |
| `layerling_read_scene` | читает сцену, выделение, единицы измерения и точные размеры всех объектов |
| `layerling_list_objects` | перечисляет все объекты с размерами, положением, поворотом и id |
| `layerling_select_objects` | выделяет объекты |
| `layerling_delete_objects` | удаляет объекты |
| `layerling_create_shape` | создаёт фигуру: куб, цилиндр, текст (в том числе по дуге), резьбу, шестерню, тело из эскиза и все остальные |
| `layerling_import_file` | импортирует файл, как это делает окно импорта; цветной OBJ или 3MF - как одно тело на цвет, а 3MF с несколькими объектами - по телу на объект |
| `layerling_import_mesh` | приносит треугольную сетку в проект |
| `layerling_update_object` | меняет размеры, положение, цвет, имя, тело или отверстие и всё остальное, из чего состоит фигура |
| `layerling_align_objects` | выравнивает объекты друг относительно друга |
| `layerling_lay_flat` | укладывает объект одной гранью на стол |
| `layerling_open_group` | открывает группу, чтобы менять её детали по одной, в том числе группу внутри открытой |
| `layerling_close_group` | снова закрывает её («Готово») или отменяет |
| `layerling_group_objects` | группирует объекты |
| `layerling_split_objects` | разрезает тела или отверстия надвое плоскостью |
| `layerling_ungroup_objects` | растворяет группы |
| `layerling_boolean_cut` | вырезает тела отверстиями |
| `layerling_intersect_objects` | оставляет только то, что есть общего у объектов (пересечение) |
| `layerling_separate_parts` | разделяет фигуру на её отдельные части |
| `layerling_list_edges` | перечисляет настоящие кромки CAD у объекта |
| `layerling_apply_edge_treatment` | обрабатывает фаской или скруглением выбранные кромки |
| `layerling_hollow_object` | выдолбливает тело со стенкой равномерной толщины |
| `layerling_array_objects` | размножает в ряд или по кругу |
| `layerling_bundle_objects` | связывает объекты, как Ctrl+B: они перемещаются вместе, сохраняют цвет и вид и выходят в выгрузку отдельно |
| `layerling_measure_section` | измеряет на плоскости разреза между двумя точками, которые привязываются к контуру: толщину стенки, зазоры, посадки |
| `layerling_show_overhangs` | включает или выключает штриховку нависаний, задаёт угол и сообщает для каждого тела площадь, которой нужны поддержки |
| `layerling_estimate_print` | оценивает объём, вес и филамент для выделения или всего проекта, считая как для сплошного тела, как в окне выгрузки |
| `layerling_inspect_errors` | показывает последнее сообщение и последнюю ошибку, а также сообщения и ошибки сеанса |
| `layerling_wrap_around_cylinder` | оборачивает тело, лежащее плоско, например SVG или текст, вокруг цилиндра - наружу или внутрь, как гравировку |
| `layerling_save_custom_shape` | сохраняет тела как собственную фигуру, на сервере или в браузере, чтобы вставлять их в другие проекты |
| `layerling_list_custom_shapes` | перечисляет собственные фигуры на сервере и в браузере |
| `layerling_insert_custom_shape` | вставляет собственную фигуру в открытый проект, при желании в точку x/z |
| `layerling_delete_custom_shape` | удаляет собственную фигуру; вставленные тела остаются |
| `layerling_show_workplane` | скрывает и показывает стол с его сеткой, например для снимка нижней стороны (только вид) |
| `layerling_set_section_view` | вскрывает вид по плоскости, чтобы заглянуть внутрь (только вид, ничего не разрезается) |
| `layerling_export_section_svg` | возвращает контуры на плоскости разреза как SVG в масштабе 1:1, из тех же тел, что и при выгрузке |
| `layerling_set_workplane` | ставит рабочую плоскость на бок тела или обратно на основание, а также скрывает или показывает её |
| `layerling_capture_image` | делает снимок вида: спереди, сверху, сбоку и другие |

Это позволяет ИИ проверять себя: он что-то создаёт, делает снимок, смотрит и улучшает.

## Пример

Вы говорите: «Сделай мне круглую коробку 60 мм в диаметре, 40 мм высотой, со стенкой 2,5 мм, открытую сверху, и плоскую крышку с надписью 'Tea' по дуге». ИИ создаёт цилиндры, выдолбливает один, ставит изогнутый текст на крышку и в конце делает снимки, чтобы посмотреть, подходит ли всё.

> **Совет:** Давайте ИИ конкретные размеры и говорите, для чего деталь («держатель для стержня 12 мм, подходит для Bambu Lab A1»). Тогда он принимает более разумные решения. И смотрите, как он строит: вы в любой момент можете вмешаться сами, потому что это тот же редактор.
