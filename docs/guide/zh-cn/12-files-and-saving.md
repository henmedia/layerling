## 设计保存在哪里

layerling 把所有内容保存在你电脑的浏览器里。没有账号，也不会上传任何内容。每次改动都会自动保存。起始页上的预览图，显示的是你用 {{ui:editor.homeDashboard}} 返回时所看到的最后一个画面。几天后在同一个浏览器里打开 layerling，一切都在。

如果从一个没有任何内容的设计返回起始页，layerling 会问是否保留它。{{ui:confirm.yes}} 或 [[Enter]] 保留，{{ui:confirm.no}} 移除，这样空设计不会越堆越多。对于服务器共享文件夹里的设计，{{ui:confirm.no}} 会把文件从服务器上删除，所有使用它的人都会失去这个文件。

这有个缺点：清除浏览器存储或换到另一台电脑的人会丢失设计。**所以要把重要的工作备份成文件。**

## 设计的文件夹

设计多达几十个时，单一列表就不够用了。在起始页上，{{ui:shared.newFolder}} 会为本浏览器的设计新建一个文件夹；点击文件夹即可打开。文件夹里可以再放文件夹。

- **移入文件夹：** 把设计拖到文件夹上，或在设计菜单里选择 {{ui:shared.moveTo}}，菜单会列出所有文件夹。打开某个文件夹时新建的设计，以及打开或导入的文件，都会落在该文件夹里。
- **再移出来：** 文件夹里的第一个磁贴 `..`，以及标签下方的那一行，都能返回上一层；也可以把设计拖到它们上面。把一个文件夹拖到另一个文件夹上，就会放进里面。
- **重命名和删除** 在文件夹的菜单里。删除文件夹不会删除任何设计：里面的内容会上移一层。
- **搜索** 会查找所有文件夹；找到的设计会显示它所在的文件夹，点击该文件夹即可打开。

{{ui:dashboard.backupAll}} 会保留文件夹：设计连同文件夹一起装进备份文件，恢复备份时会把它们放回原处。本浏览器的文件夹与服务器上的文件夹是分开的。卡片图片也会写进文件，所以恢复后马上就能看到。

## 备份与转交

在起始页上，每个设计都有一个菜单，可以重命名、复制和删除。标签旁边的那一排按钮在每个标签上都一样。要一次删除多个设计，点击 {{ui:dashboard.select}}：点击一张卡片即可选中它（勾号表示已选），{{ui:dashboard.selectAll}} 选中列表中的所有设计，{{ui:common.delete}} 对它们只询问一次。{{ui:dashboard.selectDone}} 或 [[Esc]] 退出选择。用 {{ui:dashboard.backupAll}} 可以把当前打开的标签中的所有设计打包成一个 ZIP 文件。紧挨着它的 {{ui:dashboard.restoreBackup}}（在新电脑上、还没有设计时也会出现）可以把它们恢复回来，换一个浏览器或换一台电脑也行；{{ui:dashboard.importGeometry}} 也能打开同一个文件。本浏览器的 {{ui:myShapes.title}} 会随同一个文件一起走，放在 `Custom shapes` 文件夹里，参见[形状](chapter:shapes)。如果把备份恢复到已经有其中一些设计的浏览器，那些设计不会重复添加；提示会说明有多少个已经存在。无法读取的设计会被略去，提示会写出它的名字。如果页面在备份中途重新加载——通常是因为一个很大的设计占满了浏览器允许的全部内存——起始页随后会说明在哪个设计处停下：把那个设计单独存成文件（见下文），或简化它最大的网格，然后再备份一次。本浏览器的设计上方有一行简短的提醒，说明它们没有保存在其他任何地方。

只备份部分设计：点击 {{ui:dashboard.select}} 后，{{ui:dashboard.backupSelected}} 只把所选设计连同其文件夹打包成一个 ZIP 文件；文件夹菜单中的 {{ui:dashboard.backupSelected}} 会打包该文件夹及其中所有设计和文件夹。两者都不包含自定义形状，{{ui:dashboard.restoreBackup}} 可以像完整备份一样恢复它们。这适用于此浏览器中的设计。

如果某个设计打开很慢或根本打不开，通常是因为它的撤销步骤历史记录变得非常大，请在开始页面该设计的菜单中选择 {{ui:dashboard.openWithoutHistory}}。layerling 随后只读取当前状态，永久删除所有更早的步骤并打开设计；由于无法撤销，会先询问一次。若想保留这些步骤，请先用 {{ui:dashboard.backupSelected}} 备份该设计。

在编辑器里备份单个设计：{{ui:editor.export}}，选择 **LYL** 格式，然后点击 {{ui:export.saveProject}}。LYL 文件是 layerling 自己的设计格式，包含所有内容：形状、分组、草图、CAD 数据、导入的源文件和历史记录，也就是撤销步骤。在 {{ui:export.historyTitle}} 下选择带上前多少步；初始值取自设置（功能区里的齿轮）中 {{ui:workspace.history}} 保留的步数。最后一档 {{ui:export.historyNone}} 只保存设计的当前状态——这是分享不带撤销步骤的文件的办法。导出的是副本，文件名由你在 {{ui:export.fileName}} 中指定；浏览器里的设计仍保留自己的历史记录。旧版本留下的 `.skf` 文件仍可打开，打开后会存成 `.lyl`。

**保存到自己的文件夹（Chrome 和 Edge）。** 在这些浏览器里，按钮会打开系统的保存对话框，你可以自己选择文件夹和文件名，也可以替换已有文件。之后按 [[Ctrl]]+[[S]] 会把设计再次保存到同一个文件，不再弹出对话框。用 {{ui:dashboard.importGeometry}} 或导出窗口的打开按钮从 `.lyl` 文件打开的设计，也会保存回该文件。浏览器可能会询问一次修改文件的权限。页面重新加载后，设计会忘记自己的文件，下次 [[Ctrl]]+[[S]] 时会再次询问；对话框会从你上次使用的文件夹开始。Firefox 和 Safari 不允许网页这样写入文件。在那里，文件仍会下载到“下载”文件夹，[[Ctrl]]+[[S]] 会再次下载；Firefox 可以在“设置 > 常规 > 下载”里设为每次都询问文件夹。如果你在那里给文件起了别的名字，设计会保留自己的名称，因为文件名中的版本号或日期往往是有意为之；保存后的提示会提供 {{ui:status.renameDraftToFile}}。

## 附件

说明书、零件清单、笔记、照片或数据表都可以作为文件跟设计放在一起。功能区 {{ui:editor.group.file}} 组中的 {{ui:editor.attachments}}（回形针）打开列表；回形针上的小圆点表示设计里有附件。

- **{{ui:attachments.upload}}：** 选择一个或多个文件：`.md`（Markdown）或 `.txt` 纯文本（UTF-8）、`.png`、`.jpg`、`.jpeg` 或 `.webp` 图片，或 `.pdf` 文档。文件按内容检查，名不副实的文件会被拒绝，其他类型（包括 `.svg`）不能附加。文本文件最大 2 MB，图片 16 MB，PDF 32 MB；一个设计最多 32 个文件，合计 64 MB。
- **列表：** 箭头按上传时的原样下载文件。垃圾桶删除文件；该行会先再确认一次。删除的文件无法通过撤销恢复，因为附件不属于撤销历史。
- **阅读文件：** `.md` 或 `.txt` 文件那一行的眼睛图标会在窗口中打开它供阅读，无需下载。Markdown 以排版形式显示，包括标题、列表、勾选框、表格和代码；文本文件按原样显示。只有指向网页和电子邮件地址的链接有效，并在新标签页中打开。文件中引用的图片不会加载，而是显示其描述。按 Esc、点叉号或在窗口外单击即可关闭。在历史记录视图中也可以阅读。
- **查看图片：** 图片那一行的眼睛图标会在同一窗口中打开它，图片较大时会缩小以适应窗口。PDF 没有眼睛图标：请下载后用你平时阅读 PDF 的程序打开。
- **名称已存在：** layerling 会询问如何处理。{{ui:attachments.replace}} 把新内容放进同名文件，该文件保留在列表中的位置。{{ui:common.rename}} 以另一个名称添加新文件，并建议第一个可用名称，例如 `notes 2.md`。叉号则不添加新文件。大小写视为相同，再次上传同一个文件不会有任何变化。

附件和其他内容一样随设计保存：在浏览器中、在 LYL 文件中、在备份中，以及在服务器上的设计中（添加或删除附件后立即同步到服务器）。它们不会随 {{ui:import.insertProject}} 或自定义形状一起带过去，错误报告中也不包含附件。带附件的设计会保存为较新的 LYL 文件格式：较旧的 layerling 会提示无法打开，而不是丢掉这些文件。没有附件的设计保存方式与以前完全相同。

## 导出

点击 {{ui:editor.export}}，或按 [[Ctrl]]+[[E]]。

![导出窗口，包含 STL、3MF、OBJ、STEP、SVG、PNG、LYL 和 2D 格式。](shot:export-panel)

顶部是文件名，下面选择格式。有选中项时只导出选中的内容，否则导出整个设计。如果选择漏掉了可见部件，窗口里会明确提示，{{ui:export.selectAll}} 可以一键选中所有可见内容。文件写好后窗口会自动关闭；导出失败时，窗口会保持打开并显示消息。

| 格式 | 用途 | 注意事项 |
| --- | --- | --- |
| **STL** | 切片软件和 3D 打印 | 三角网格。最简单、最通用的格式。STL 没有部件之分：重叠的实体会合并成一个网格。要保留为独立部件，请导出 3MF。在 Chrome 和 Edge 中，第一次导出 STL 会询问保存位置，之后该设计再导出 STL 都会写入那个文件，直到你在文件名字段里输入别的名字，或按 {{ui:export.stlSaveAs}}。 |
| **3MF** | 带颜色的切片软件 | 每个实体都保持为独立部件，并带有名称和颜色。重叠的实体只有在颜色相同时才会合并；当一个形状位于另一种颜色的实体内部时（比如板子上的标志），先建的那个会给后建的让出空间。适合 PrusaSlicer、Bambu Studio、OrcaSlicer 和 Cura。Bambu Studio 和 OrcaSlicer 打开时会询问如何把颜色对应到你的耗材，并称该文件“不是来自 Bambu”——这条消息没有影响。 |
| **OBJ** | 建模与交换 | 支持广泛的网格格式。颜色以顶点色保存在同一个文件里，不需要额外的 `.mtl`。Bambu Studio 和 OrcaSlicer 能读取颜色，并像 3MF 那样询问如何对应到耗材；其他程序只能看到形状。与 3MF 一样，重叠的实体只有在颜色相同时才会合并。 |
| **STEP** | 完整的 CAD 程序 | 把长方体、圆柱体、球体和圆锥体保留为精确几何，因此也包括由轮廓生成的形状（星形、心形、椭圆、管、半球、圆弧屋顶、圆角长方体、燕尾、孔等）、弯管、楔形、棱锥、抛物面体、螺纹、弹簧和齿轮，以及圆角和倒角。一次会话中第一次导出 STEP 会加载一次 CAD 内核（约 22 MB）。 |
| **SVG** | 激光切割机和绘图仪 | 以毫米为单位的干净俯视图，包含孔和曲线轮廓。在 {{ui:export.svg.view}} 下，{{ui:export.svg.viewFootprint}} 只输出物体立在工作平面上的轮廓。{{ui:export.svg.viewEdges}} 把从上方看到的边输出为线条，每个实体用它自己的颜色；见下文。 |
| **DXF** | 激光切割加工厂 | 同样的俯视图（{{ui:export.svg.viewSilhouette}} 或 {{ui:export.svg.viewFootprint}}），输出为一条由直线、真正的圆弧和圆组成的轮廓——没有多段线、样条曲线，也没有由短直线段拼成的曲线——位于 0 图层、白色，DXF 2000 格式，单位毫米，不镜像。相互接触的实体合并为一条轮廓，因此没有线会被切割两次。加工厂要求每个文件一个零件：导出前先选中该零件。尚未在激光切割机上实测：欢迎反馈。 |
| **PNG** | 论坛帖子、打印站点、提问 | 当前视图的图片，分辨率为两倍，不含手柄、选择框和尺寸。{{ui:export.png.plate}} 和 {{ui:export.png.transparent}} 在窗口中设置。先旋转和缩放，直到画面合适；这里选中项无关紧要。 |
| **LYL** | layerling 本身 | 可编辑的设计，包含与之相关的所有内容。 |
| **2D** | 工坊、车床和铣床、文档 | 1:1 的图纸，可导出为 PDF 或 SVG：ISO 图纸上的主视图、俯视图和右视图。见下文。 |

**会掉出来的部分用连接桥（DXF 和 SVG）。** 用激光或绘图仪切割带文字的板时，o、a、b 这类字母的中间会掉出来。在 DXF 的导出窗口中，或在使用俯视图的 SVG 的导出窗口中勾选 {{ui:export.bridges}}，小小的连接桥就会像镂空模板那样把这些部分连在周围的材料上：旁边可设置 {{ui:export.bridgeWidth}}（0.5 到 3 mm）和 {{ui:export.bridgeCount}}（1 到 4）。连接桥从不碰到其他轮廓或其他桥，也从不留下窄到无法切割的缝；只能互相支撑的部分也会被连到板上。如果某个部分在所选宽度下得不到连接桥，导出后的消息会说明有几个。不勾选时什么都不会改变。

**把 STL 存到你自己的文件夹（Chrome 和 Edge）。** 在那里，一个设计的第一次 STL 导出会打开系统的保存对话框，你可以自己选文件夹和名称，也可以替换已有文件。之后该设计的每次 STL 导出都会不经对话框直接写入同一个文件；导出窗口会显示是哪个文件，导出按钮旁的 **另存为…** 可另选一个。对话框会记住它自己的文件夹，与设计的文件夹分开，这样切片文件可以留在切片软件旁边。重新加载页面后，设计会忘记它的 STL 文件，下次导出会再次询问。Firefox 和 Safari 仍像以前一样下载文件。如果你更希望每个 STL 都是普通下载，让浏览器像 Tinkercad 那样给已用过的名字编号（`name (1).stl`、`name (2).stl`），请在设置的 {{ui:workspace.appearance}} 下打开 {{ui:workspace.stlAsDownload}}。

在 {{ui:export.svg.view}} 下选择 {{ui:export.svg.viewEdges}} 时，SVG 会按你从上方看到的样子显示设计，就像图纸的俯视图：每条看得见的边都是一条线，被其他零件挡住的边会略去。每条线都有其实体的颜色，因此按颜色分类的激光或绘图仪软件会把每种颜色放到单独的图层上。每个图层是切割、划线还是雕刻，在那里选择。

**把 STL 保存到自己的文件夹（Chrome 和 Edge）。** 在这些浏览器里，第一次为某个设计导出 STL 会打开系统的保存对话框，你可以自己选择文件夹和名称，也可以替换已有文件。之后该设计的每次 STL 导出都会写入同一个文件，不再弹出对话框；导出窗口会显示是哪个文件，导出按钮旁的 **另存为…** 可以另选一个。对话框会记住自己的文件夹（与设计用的文件夹分开），这样切片文件可以和切片软件放在一起。页面重新加载后，设计会忘记自己的 STL 文件，下次导出会再次询问。Firefox 和 Safari 仍像以前一样下载文件。

没有分组的孔在导出时会从它触及的每个实体上挖掉，与视图显示的一致。所以不必在每次导出前先分组。有选中项时，只有选中的孔才计入。孔不能单独导出；layerling 会提示这一点。

STEP 只携带精确的 CAD 实体。导入的网格会像{{ui:editor.tool.makeExact}}那样为文件转为精确实体（见下文“将导入的网格转为精确实体”），因此导出可能需要最多一分钟；大部分为自由曲面的网格（如人偶）以及其他无法精确写出的内容会被略过。导出后的消息会列出这些实体并说明原因。给打印机用时，请选择 STL 或 3MF，它们能携带所有内容。

### 工坊用图纸

选择 **2D** 格式（将鼠标悬停在其上会显示“图纸”），并在文件名下方选择 PDF 或 SVG。有选中项时只绘制选中的内容，否则绘制整个可见设计；没有分组的孔仍会切掉它们触及的部件。

layerling 按第一角投影绘制主视图、俯视图和右视图（右视图在主视图左侧，俯视图在主视图下方），使用能容纳的最小 ISO 图幅，从 A4 到 A0，零件需要时可用更大的。比例始终为 1:1。每个视图都标注总宽和总高，看不见的边用虚线表示。与视图方向平行的圆孔会带中心十字和标记（F1、T1、R1），底部的表格列出它们的直径和位置，位置从视图左下角量起。右下角的标题栏包含名称、比例、单位、日期和图号。图纸上的文字跟随界面语言。

按 100 % 或“实际大小”打印，否则长度会对不上。图纸不做的事：螺纹、深度、公差和斜向孔都不标注尺寸，尺寸来自作为网格的模型，因此是名义值。过于复杂的零件（超过 100,000 个三角形）或超过 200 个孔会被拒绝并给出消息；这时请少选一些对象。

投影基于 WC3D 的 Cadverix-3D 的绘图工作。

### 需要多少耗材？

对 STL、3MF、OBJ 和 STEP，{{ui:export.estimateTitle}} 框会显示所导出内容的体积、重量和 1.75 mm 耗材长度。它的计算方式与文件一致：只算可见实体，减去孔，重叠只算一次。右侧选择耗材——PLA、PETG、ABS、ASA、TPU 或 PA（尼龙）——重量随其密度变化。体积是实体本身的体积。重量和耗材是按带壁和填充的打印做出的粗略估计：在标题下设置 {{ui:export.estimateInfillLabel}}（初始为 15 %）和 {{ui:export.estimateWallsLabel}}（2），框里会说明它计算了什么，以及同一个零件实心时会有多重。真正的数字由切片软件自己的设置决定，所以把它当作参考：适合比较设计，也适合判断线轴够不够用。填充为 100 % 时，框会把零件当作实心计算，这是上限。 框会在你按下 {{ui:export.estimateCalculate}} 时才计算数字，因此即使是精细描摹的模型，导出窗口也会立即打开。

## 导入

用 {{ui:editor.import}} 或 [[Ctrl]]+[[I]] 可以把外部文件带入设计。

![导入窗口：打开或插入设计，拖入几何体。](shot:import-panel)

- **{{ui:import.openProject}}：** layerling 设计（`.lyl`，或更早的 `.skf`）会作为新设计重新打开。
- **{{ui:import.insertProject}}：** layerling 设计的实体会添加到当前设计中。适合那些需要反复使用的基本形状：建一次、保存，然后每次带进来。 把一个或多个 `.lyl` 文件拖到下方的放置区，也会以同样的方式插入。它的[便签](chapter:measuring-and-notes)会一起进来，以收起状态出现，并接在设计中已有便签之后继续编号；它的参考点也会一起进来。
- **{{ui:import.insertFromServer}}：** 对保存在服务器上的设计同样适用（有服务器存储时显示）。选择文件夹并点击设计，其实体会添加到当前设计。
- **添加几何体：** 把 STL、OBJ、3MF、STEP、SVG、PNG 或 JPG 文件拖到窗口中，或点击选择文件。导入的网格可以旋转、移动、用孔切割，也可以在上面继续建模。SVG 会作为草图实体导入，来自 picsvg.com 或 Inkscape 的“位图描摹”等描摹工具的也一样：它的轮廓变成草图的直线和曲线，高 4 mm，从上方看与图纸方向一致。在属性面板中设置它的 {{ui:prop.sketchFill}}（区域，或向外、向内、居中的描边），{{ui:prop.sketchSilhouette}} 会忽略孔，参见[草图](chapter:sketches)的“填充与剪影”。点本身要在草图模式下修改。如果要按自己的尺寸导入，先在导入窗口的 **SVG 和图片：宽度（mm）** 下输入宽度，与 Tinkercad 一样：图纸会缩放到这个宽度，高度和深度随之缩放，这个字段在这一次导入后就会清空；留空时，SVG 按自身尺寸导入，图片则宽 50 mm。只有超过 2500 条直线和曲线的非常复杂的 SVG 才会作为固定网格导入。PNG 或 JPG 图片会被描摹成轮廓，以同样的方式作为草图实体导入，宽 50 mm，之后可以调整大小：图片中不是背景的部分会保留，背景是占据图片边缘更多的部分。只包含一张图片的 SVG 也按同样方式描摹。无法构成实体的形状，比如自相交或在一点处自接触的轮廓，会被略过，导入后 layerling 会说明有多少个。这时可以在绘图软件里把重叠的部分合并、闭合轮廓，然后重新保存文件。在同一页上绘制的图纸（例如把一个文档的各图层分别导出为文件）会重新对齐，只要在导入前打开导入窗口中的 {{ui:import.keepSvgPage}}：每个都保留自己在页面上的位置，否则每个都会以自身为中心。用多种颜色绘制的 SVG 同样按颜色各导入为一个实体，各自保持颜色和位置；超过 12 种颜色（如描摹的图片）则仍为一个实体。彩色 OBJ 或 3MF 会按颜色各导入为一个实体，各自在原来的位置。在 OBJ 中，颜色要么在文件本身里（如 layerling 导出的 OBJ），要么在旁边的 `.mtl` 里。把那个文件也一起选中，或者像 Tinkercad 交付 OBJ 那样导入整个 ZIP。3MF 自带颜色，在 Bambu Studio、OrcaSlicer 或 PrusaSlicer 的项目中，每个部件采用其耗材的颜色。包含多个对象的 3MF（例如每盘一个对象的项目）会按对象各导入为一个实体；切片软件中的修改器、负体积和支撑阻挡器会被略过。切片软件里涂在面上的颜色不会被读取。
- **DXF：** 激光切割加工厂或供应商发来的零件轮廓 DXF，会作为可以继续编辑的零件导入：每条闭合轮廓变成一个高 4 mm 的实体，其中的每个孔变成旁边一个独立的孔（圆孔为圆柱），所以在 3D 编辑器中可以像其他孔一样移动孔、改变孔的大小；要移动整个零件，请全部选中。单位为毫米（英寸文件会换算，没有单位的文件按毫米读取），圆弧和圆保持为真正的圆弧。读取直线、圆弧、圆、椭圆、多段线、样条曲线和块；文字、尺寸标注和填充图案会被略过，未闭合的轮廓也会被略过——提示信息会说明有多少个。厚度在属性面板中设置。
- **来自 Tinkercad：** 从 Tinkercad 导出的 STL 或 OBJ 会像其他网格一样作为几何体导入，OBJ 会保留颜色。真正的形状则可以通过社区的一个免费工具带过来：taylormadearmy 的 [Export to layerling](https://taylormadearmy.github.io/tinkercad-layerling-importer/)，这是一个书签，能在你的浏览器里把 Tinkercad 设计转换成 `.lyl` 文件，然后在这里用 {{ui:import.openProject}} 打开。它不属于 layerling，我们自己还没有测试过；作者在 Windows 的 Chrome 上测试过。

用**较新版本的 layerling**保存的设计，可能包含你这个版本还不认识的内容，比如新形状、新设置或自定义字体。如果 layerling 因此无法打开，消息会写出两个版本号。如果能打开，提示会说明较新的内容在这里可能看起来不同。无论哪种情况，刷新页面都有帮助：layerling.com 总是提供最新版本。安装版应用会在下次启动时获取更新；在自己的服务器上，你需要自行安装更新。

模板图片在草图模式下添加，参见[草图](chapter:sketches)。

## 简化导入的网格

扫描或雕刻得到的网格，三角形数量往往远超其形状所需，而你在移动、切割和保存时，每一个三角形都会被带着走。修改组里的 {{ui:simplify.title}}（或实体的右键菜单里）会把当前网格与你选择保留的三角形比例所留下的结果并排显示；两个视图都会随工作平面的鼠标按键一起旋转和缩放。按百分比或三角形数量设置保留多少，{{ui:simplify.apply}} 会采用更轻的网格。结果是普通网格：对于切割或合并的结果，{{ui:group.edit}} 及其原始部件会被放弃。开启{{ui:simplify.keepEdges}}（默认开启）时，锐边和孔的边缘会精确保持原位，而平面仍会去掉大部分三角形；关闭后，简化可能把它们磨圆以达到更少的三角形。
如果简化停在你要求的数量之上，窗口会说明原因：开启 {{ui:simplify.keepEdges}} 时，由平面和锐边组成的物体（例如立方体和楔形）往往无法再减少。

切割、合并和相交导入的网格是在浏览器里计算的，所以工作区设置限制了这类网格可以有多少个三角形（{{ui:workspace.booleanTriangleLimit}}）。超过限制的网格不会被处理，消息会写出它的三角形数量；请先简化网格，或者在电脑能承受的情况下提高限制。

## 将导入的网格转为精确实体

STL、OBJ 或 3MF 文件只包含三角形，即使零件是在 CAD 中用平面和圆孔画出来的。“{{ui:editor.group.modify}}”区域中的{{ui:editor.tool.makeExact}}（或物体右键菜单中的同名命令）会在这些三角形中找出构成它们的平面、圆柱面、圆锥面、球面和圆环面，并用它们把物体重建为精确的 CAD 实体：一个孔会变成一个带圆形边缘的真正圆柱面，而不是上百条窄条。之后，{{ui:editor.tool.fillet}}和{{ui:editor.tool.chamfer}}沿一条干净的边进行，{{ui:editor.tool.deleteFace}}可去掉整个圆角或孔壁，STEP 导出也会带上真正的面。状态栏会显示找到了什么，例如“平面：9、圆柱面：4”。

与这些曲面都不吻合的部分会保留为小平面片，消息会说明它们占表面的多少。大部分为自由曲面的物体（如人偶或雕塑造型）仍保持为网格；有缺口或墙面相互交叉、无法闭合成实体的网格也一样。最多可处理 400,000 个三角形，大型网格可能需要几分钟。更大的网格可先用{{ui:simplify.title}}并开启{{ui:simplify.keepEdges}}降到这个数量以下；否则请直接使用原样的网格，这样结果最干净。撤销一步即可恢复网格。

对于带圆形面的小网格（最多 4,000 个三角形），边工具会自动完成这一步：给这样的 STL 倒圆角时，会先以同样方式重建它。

## 报告问题

如果 layerling 做出意外的事，可以保存一份 {{ui:editor.bugReport}}：链接在底部的页脚里，论坛旁边。它是一个 ZIP 文件，因为 GitHub 和许多论坛不接受单独的 .lyl：里面有你的设计（.lyl）和一个简短的文本文件，记录版本、浏览器、屏幕尺寸、最后的消息和任何错误。起始页可以像备份一样打开这个 ZIP，也可以解压后打开其中的 .lyl。里面没有个人信息。把文件附在论坛或 GitHub 的帖子里，这样就能用和你完全一样的设计来追查问题。

如果 layerling 因错误而停止，会显示一个带错误消息的窗口，而不是空白页。你可以从中把浏览器最后保存的设计状态存成 .lyl 文件、返回总览，或新建一个设计。窗口中的错误消息和保存的文件在你报告问题时会有帮助。

## 服务器上的共享设计

当 layerling 运行在你自己的电脑或 Web 服务器上时，它可以提供一个共享文件夹，所有用户都在里面保存设计。起始页这时会用两个标签显示设计：{{ui:shared.trailRoot}} 对应共享文件夹，另一个对应本浏览器，每个标签都标有其中的设计数量；设计较多的那个排在前面并默认打开。你可以在那里创建文件夹、拖动设计来移动它们，并在整个文件夹中搜索。存放在那里的设计会自动保存回该处。本浏览器中的设计，可以通过把卡片拖到 {{ui:shared.trailRoot}} 标签上来放到服务器上，也可以使用卡片菜单里的 {{ui:dashboard.sendToServer}}。当 {{ui:shared.trailRoot}} 标签打开时，{{ui:dashboard.createDesign}} 和 {{ui:dashboard.restoreBackup}} 会把设计放进你打开的服务器文件夹，{{ui:dashboard.backupAll}} 则会把服务器上的所有设计（连同其文件夹）及其自定义形状打包成一个 ZIP 文件。起始页按文件名显示设计，所以在卡片上或编辑器顶部重命名设计，也会重命名服务器上的文件。删除设计或文件夹会永久删除它，连同本浏览器里的工作副本。保存在服务器上的自定义形状位于其 `Custom shapes` 文件夹中，参见[形状](chapter:shapes)。

有两件事能让这更快：起始页上的 {{ui:dashboard.sendAllToServer}} 可以一次性把本浏览器的所有设计放到服务器上；勾选 {{ui:dashboard.newOnServer}} 会让每个新设计都从服务器文件夹开始，因此从第一次修改起就保存在那里。这个勾选状态保存在本浏览器中。无法放上去的设计（比如名字在服务器上已被占用）会留在浏览器里，消息会说明有多少个。

其他导出格式（STL、3MF、OBJ、STEP、SVG、PNG 和图纸）也可以放进同一个文件夹：在导出窗口中，{{ui:export.saveToShared}} 会把文件写到你的设计旁边；对于不在服务器上的设计，则写到起始页上打开的文件夹里。共享该文件夹的程序，比如 Docker 中的切片软件，可以从那里打开它。该文件不会出现在设计列表中。如果那里已有同名文件，消息会说明，再按一次按钮就会替换它。

这不是同时编辑：每个打开文件的人都在自己的副本上工作。如果别人在此期间改过该文件，layerling 会拒绝覆盖它。

在 layerling.com 上，此功能未启用。如何在自己的服务器上设置，见 [GitHub 上的 README](https://github.com/henmedia/layerling/blob/main/README.md)。
