## 手指与触控笔

layerling 可在平板的浏览器中运行，也可从主屏幕作为应用运行。手指的作用相当于鼠标左键。平板没有的三样东西——鼠标右键、Shift 键和滚轮——各有自己的替代方式：

| 你想要 | 在平板上 |
| --- | --- |
| 选择一个实体 | 点击它。 |
| 选择多个实体 | 手指按住不动半秒，选择 {{ui:contextMenu.selectMultiple}}，然后逐个点击实体。再次点击已选中的实体会将其取消。 |
| 全选实体 | 在空白处按住手指不动半秒，选择 {{ui:contextMenu.selectAll}}。 |
| 打开右键菜单 | 在实体上或空白处按住手指不动半秒。 |
| 移动实体 | 拖动它。 |
| 调整实体大小、旋转或抬高 | 拖动它的控制柄，即周围的小方块和箭头。手指在稍偏一点的位置也能抓住它们。 |
| 转动视图 | 在空白处用一根手指，或拖动视图立方体。 |
| 缩放视图 | 两根手指：张开靠近，捏合远离。 |
| 移动视图 | 两根手指并拢滑动。 |
| 清除选择 | 点击空白处。但在 {{ui:camera.touchRotate}} 开启时不行，那时单指用于转动视图；而在 {{ui:contextMenu.selectMultiple}} 中，第一次点击空白处只会结束该模式并保持选择不变，下一次点击才会清除。 |

## 选择多个实体

没有 Shift 键时，长按菜单中的 {{ui:contextMenu.selectMultiple}} 起到电脑上 Shift+点击的作用。开启期间会有提示说明，每次点击实体会将其加入选择或从中移除。点击空白处，或在键盘上按 [[Esc]]，会结束该模式并保持选择不变。与此同时，手指在空白处仍可转动视图。随后 {{ui:editor.tool.group}}、{{ui:editor.tool.align}} 或移动操作会作用于你选中的所有实体。

同一菜单中还有 {{ui:contextMenu.carry}}，即触屏上的 [[C]] 键。选中项随后会跟随手指越过其他实体的各个面；点击一下即可将其放到你点击的那个面上，斜面也可以，而且第一次点击就足够。也可以搜索“set down”或“cruise”找到该菜单项（命令搜索，键盘上为 [[Ctrl]]+[[K]]）。

## 转动与缩放视图

在空白处用一根手指转动视图，两根手指缩放并移动视图。从实体上开始的手指操作的是实体，而不是视图。如果你更希望它转动视图，请在视图栏中开启 {{ui:camera.touchRotate}}：此后无论从何处开始，单指都会转动视图而不是选择。该开关仅在带触摸屏的设备上显示。

左上角的视图立方体在拖动时会转动视图，点击它的某个侧面、角或边会跳到该视图。参见[视图与工作平面](chapter:view-and-workplane)。

## 控制柄、小点与触控笔

指尖会遮住它所瞄准的东西。layerling 允许手指比鼠标指针伸得更远一点去够控制柄、点、线和边，但触控笔更精细。这适用于平板识别为笔的笔，例如 Apple Pencil 或 S Pen。带橡胶笔尖的普通触控笔会被屏幕当作手指，并不比手指更精细，所以只能像手指一样使用。在 iPad 上悬停于屏幕上方的 Apple Pencil 稍后还会在一个小气泡中显示控件的名称，就像鼠标指针的提示框那样。

如果实体在儿童或匆忙的手触碰时会被挪动，请在设置中开启 {{ui:workspace.selectBeforeMoving}}：这样必须先选中实体，只有下一次拖动才会移动它。

## 在 iPad 或 iPhone 上

- **将其安装为应用。** 在 Safari 中点击分享图标，选择“添加到主屏幕”。应用会在自己的窗口中打开，没有地址栏，并且无需连接即可使用，参见[离线与安装](chapter:offline-and-install)。
- **你的设计保存在浏览器中。** 没有账户，也不会上传任何内容。Safari 有一条自己的防跟踪规则：如果七天内在 Safari 中没有访问过某个网站，它会删除该网站存储的内容。添加到主屏幕的 Web 应用不受该规则限制，WebKit 的文档如此说明。这也是更充分的理由去使用主屏幕上的应用，并备份重要作品：起始页上的 {{ui:dashboard.backupAll}} 会把所有设计打包成一个文件。
- **文件。** Safari 只允许页面通过下载来写入文件，所以 {{ui:editor.export}} 会把文件放进“文件”应用的“下载”中，键盘上的 [[Ctrl]]+[[S]] 会再次下载它；参见[文件与保存](chapter:files-and-saving)。
- **无需键盘。** 每个工具在功能区中都有按钮，数字输入框会调出屏幕键盘。iPad 上的键盘还会带来[键盘快捷键](chapter:shortcuts)。 实体旁的数值框要点第二下才会打开数字输入框：第一下只是标记它，所以手指误触到它也不会弹出键盘。

## 带儿童的课堂

手指与橡胶笔尖的触控笔在这里用法相同。有两项设置能让课堂更轻松：{{ui:workspace.selectBeforeMoving}} 让触摸不会意外移动实体，{{ui:camera.touchRotate}} 让单指始终转动视图。功能区“帮助”组中的问号按钮会开启 {{ui:interactiveHelp.title}}：此时点击任何按钮、输入框或控制柄都会给出说明，再次点击该按钮或按 [[Esc]] 即可退出。

要让整个班级使用，请在设置中开启 {{ui:workspace.simpleMode}}。功能区随后只保留课堂上用到的工具（复制、粘贴、复制副本、删除、撤销、分组、镜像、倒角、圆角、抽壳、对齐、导出），形状库只保留一个短列表，按钮更大，起始页只显示设计，别无其他：没有新闻、没有欢迎文字、没有帮助按钮，也没有指向 layerling 之外的链接。开启只需点击一下；关闭则要按住随后取代它的那个按钮两秒钟。以 `?mode=simple` 结尾的链接会为打开它的设备开启该模式，`?mode=full` 会再次关闭。在服务器上运行 layerling 的人可以用 `LAYERLING_SIMPLE_MODE=true` 让所有人一开始就处于该模式，或用 `always` 为所有人固定下来，这样程序就没有退出的开关；参见 README。
